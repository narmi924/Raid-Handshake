# Raid Handshake — 2:45 real demo recording script

All spoken narration and captions below are English. Capture real Twitch operation and the
actual Codex build thread. The final video is not yet recorded or uploaded.

## Capture one real run first

- Show both A and B actually live, B's HTML/audio or other authorized content, the local control
  room with **Summary ready**, and B's OBS overlay in the actual Twitch video.
- Record continuously from before `/raid` through at least five minutes after arrival. Keep the
  raw original, including the waiting interval. Use a genuine participant for useful connection
  and speech counts; retain zeros if those are what the actual run reports.
- Keep the exact-preview/manual-send path. Frame the full card, the confirmation action and
  the resulting Twitch chat message. Measure from the real arrival shown in the recording.
- Capture the five-minute card's actual observation time. After preserving the raw recording,
  compress the wait with an explicit caption such as **“5 minutes after the real raid”**.
- Separately capture the Codex thread, relevant edits and the real test output. Avoid pages
  containing API keys, activation codes, stream keys, passwords or unrelated private content.
- Use owned/authorized visuals and audio. No fake raid button, injected EventSub notification,
  manufactured chat/counts, or generated product animation should stand in for live evidence.
